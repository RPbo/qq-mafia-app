# Публикация QQ Mafia в Google Play и App Store

Игра работает как сайт https://mafia.qqhtml.online, приложения — оболочка над ним. Обновления игры (правила, экраны, ивенты) приходят с сервера сразу, без проверки магазинов; магазины нужны только для обновления самой оболочки.

## Что собирается автоматически
| Платформа | Что | Где взять |
|---|---|---|
| Android | `qq-mafia.aab` для Google Play, `qq-mafia.apk` для ручной установки | Releases этого репозитория (собирается на каждый push в `main`) |
| iOS | проект `ios/` (XcodeGen) и workflow `Build iOS (TestFlight)` | запускается вручную, нужны секреты Apple (ниже) |

Самообновление через GitHub Releases из приложения убрано (правила Google Play). Версия = номер сборки в Actions.

**Важно:** храните резервную копию ключа подписи (секрет `KEYSTORE_B64` и пароли). Потеряете ключ загрузки — придётся восстанавливать доступ через поддержку Google.

## Перед отправкой на проверку (сервер)
1. На Railway задайте `REVIEW_CODE` (например, `openssl rand -hex 12`) и `SUPPORT_URL` (e-mail со ссылкой `mailto:` или Telegram-контакт поддержки).
2. Убедитесь, что открываются `/privacy`, `/terms`, `/delete-account`, `/support`. **Прочитайте и поправьте тексты** (это черновики, юридически их должны утвердить вы).
3. Проверьте, что в приложении есть: удаление аккаунта (Настройки → Удалить аккаунт), жалобы и блокировки игроков, ссылки на политику и поддержку. Всё это уже реализовано.
4. Push на Android: секреты `GOOGLE_SERVICES_JSON` (репозиторий приложения) и `FCM_SERVICE_ACCOUNT` (Railway). В сборке сейчас предупреждение «GOOGLE_SERVICES_JSON не задан», то есть push в собранных APK/AAB не работают, пока не добавите секрет.

## Google Play
1. Создайте аккаунт разработчика Play Console (разовый платёж 25 $). Для личных аккаунтов, созданных после ноября 2023, перед выходом в production нужно закрытое тестирование: не менее 12 тестеров в течение 14 дней подряд.
2. Создайте приложение: имя «QQ Mafia», язык по умолчанию русский, игра, бесплатное.
3. Release → Production (или Closed testing) → загрузите `qq-mafia.aab`. Идентификатор пакета `online.qqhtml.mafia`. Включите Play App Signing (ключ из секрета станет ключом загрузки).
4. Store listing: тексты ниже; значок `store/play/icon-512.png`, баннер `store/play/feature-graphic-1024x500.png`, скриншоты `store/play/phone/*.png` (1080×1920, 6 штук).
5. App content:
   - Политика конфиденциальности: https://mafia.qqhtml.online/privacy
   - Удаление аккаунта: https://mafia.qqhtml.online/delete-account (и в приложении)
   - Доступ к приложению: «требуется вход». Инструкция для проверяющих: на экране входа нажать «Вход для проверяющих», ввести код `REVIEW_CODE`; в лобби нажать значок консоли и добавить ботов (нужно 4–8 игроков для старта).
   - Реклама: нет. Целевая аудитория: 13+. Категория: Игры → Настольные / Карточные (или Ролевые).
   - Возрастной рейтинг (анкета IARC): вымышленное насилие (мафия, «убийства» как игровая механика) — слабое; общение между пользователями — да; покупок нет (магазин отключён).
   - Data safety: собираются идентификатор пользователя, имя, фото профиля (из Telegram), сообщения, идентификаторы устройства (push-токен), игровая активность; данные шифруются при передаче; пользователь может запросить удаление (есть).
   - Разрешения: `INTERNET`, `POST_NOTIFICATIONS`.
6. Обновления: после каждой сборки скачайте новый `qq-mafia.aab` из Releases и загрузите в Play Console (автоматизация через Google Play API возможна позже).

## App Store (iOS)
Нужен аккаунт Apple Developer Program (99 $/год). Сборку на Mac сделает GitHub Actions.
1. В App Store Connect создайте приложение: bundle id `online.qqhtml.mafia`, имя «QQ Mafia».
2. App Store Connect → Users and Access → Integrations → создайте API-ключ (роль Admin или App Manager). Скачайте `AuthKey_XXXX.p8`.
3. В репозитории приложения Settings → Secrets добавьте: `APPLE_TEAM_ID`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (команда `base64 -i AuthKey_XXXX.p8`).
4. Actions → Build iOS (TestFlight) → Run workflow. Сборка уйдёт в TestFlight; когда она обработается, выберите её в версии приложения и отправьте на проверку.
5. Материалы: значок `store/ios/icon-1024.png` (внутри проекта уже лежит такой же), скриншоты `store/ios/iphone-6.7/` (1290×2796) и `store/ios/iphone-6.5/` (1284×2778).
6. Данные для App Privacy: имя, идентификатор пользователя, контент пользователя (сообщения), фото профиля — связаны с пользователем, для функций приложения; отслеживания нет.
7. Notes for review: «Вход обычно через Telegram. Для проверки: на экране входа нажмите «Вход для проверяющих» и введите код ______ (REVIEW_CODE). В лобби нажмите значок консоли и добавьте ботов, затем «Начать игру».»
8. Статус iOS-сборки: проект и workflow написаны, но на Mac я их не запускал, поэтому первая сборка может потребовать правок (названия схем, подписи).

### Риски отклонения (честно)
- **Guideline 4.2 (минимальная функциональность):** Apple часто отклоняет оболочки над сайтом. В пользу приложения: игра в реальном времени, чат, друзья, рейтинг. Рекомендуется добавить нативные функции (push-уведомления через APNs, виброотклик, шаринг приглашений).
- **4.8 (вход через сторонний сервис):** вход только через Telegram. Apple может потребовать добавить Sign in with Apple или эквивалентный вход. Запас: добавить вход по e-mail или гостевой вход.
- **1.2 (пользовательский контент):** есть жалобы, блокировки, контакт поддержки. Нет автоматического фильтра нецензурных сообщений; Apple может попросить его добавить и обещание реагировать на жалобы в течение 24 часов.
- **3.1.1 (покупки):** внутренняя валюта и Premium для цифровых товаров в iOS должны идти через In-App Purchase. Сейчас магазин в приложении отключён («в разработке»), внешнее пополнение в iOS-приложении заблокировано. Вернуть покупки можно только через IAP.
- **Google Play, WebView-приложения:** минимальная функциональность тоже проверяется; в пользу приложения push-уведомления и вход, сохраняемый в приложении.
